# 测量与记录口径

本项目用于手机噪声估算和现场记录辅助，不是经检定的声级计，也不提供专业鉴定、可信授时或在线存证。

## 声级

同一AudioRecord采集48kHz、PCM16单声道；优先UNPROCESSED，回退VOICE_RECOGNITION。PCM经三段SOS A计权滤波与125ms Fast指数时间计权计算，约每250ms刷新。AAC录像音轨取同一PCM源。

原始数字电平dBFS可为负。UNPROCESSED按Android标称520 PCM16 RMS对应94dB SPL换算，VOICE_RECOGNITION按2500 PCM16 RMS对应90dB SPL换算。参考源、偏移、输入配置均在元数据中保留。这是标称估算，不保证每台手机的室内读数都在特定范围。

AVG为声能平均（LAeq,T），不是对分贝数值直接求算术平均。等时长60和70dB的声能平均约67.4dB。MAX为Fast时间计权最大LAFmax，不是瞬时声压峰值。

每段录像独立累计；每张照片取快门前60秒内的有效完整一秒数据，不足60秒仅使用已有数据，窗口边缘不完整秒不纳入照片AVG/MAX。照片的取证持续时长为0，测量窗口另在元数据中描述。录像末尾不满一秒仍计入整段统计，但不会补齐CSV假数据。

曲线每秒一组声能均值和Fast最大值，保留最近60秒，缺失处断开。采集失效不以静音或旧值充当有效读数。估算声级小于0的显示可为“＜0”，原始数值仍保留。

0.1.5起移除用户校准操作页；历史用户参考配置按输入配置匹配，旧dBFS记录保留原单位。A计权数字滤波器在1kHz归一化，高频有双线性变换频率扭曲；不宣称符合IEC/ANSI计量标准。

## 水印与时间位置

OpenGL将相机画面和底部水印合成后同时输出预览、JPEG和H.264。水印写入像素，外部查看器/播放器仍可见。时间使用设备当地时间和时区，时长用单调时钟。修改系统时间记录事件，不回写既有媒体。

定位使用Android系统提供者，无GMS/地图SDK依赖，不查询地名。无定位允许继续拍摄并显示未定位；超过30秒标旧定位，仅大致权限保留大致标记。系统经纬度、精度和定位时间不证明地点真实。

## 导出

相册保存保留水印媒体，不附带全部测量元数据。完整ZIP包含已完成媒体、measurements.csv、metadata.json、locations.jsonl、events.jsonl、中文说明和SHA256SUMS.txt。清单覆盖其他导出文件，不包含自身；用于检查变化，不认证拍摄真实性。

`python tools/verify_bundle.py 取证包.zip`可独立检查包内摘要。不要把含真实坐标、声音或人像的资料包上传公开Issue。

进程中断会标记未完成记录；保留完成媒体和已落盘数据，不承诺当前未封装MP4可恢复。无水印原件、后台持续录像、云同步和可信存证未纳入本版。

参考：Android兼容性定义中的音频输入标称灵敏度，https://source.android.com/docs/compatibility/10/android-10-cdd 。

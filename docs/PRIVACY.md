# 隐私与本地数据说明

声迹分贝测量：隐私与本地数据说明
版本：1；生效日期：2026年10月26日

公开开发者：qysnb
项目与反馈：https://github.com/qysnb/DecibelEvi
问题反馈：https://github.com/qysnb/DecibelEvi/issues
反馈使用外部浏览器和 GitHub；请勿在公开问题中附上不希望公开的照片、声音、位置或其他个人信息。本应用没有收集反馈的内置网络接口。

1. 本机处理与采集时机
本应用无需账号，不申请 Internet 权限，不集成广告、分析统计或云端上传 SDK。测量、拍摄与记录管理在本机完成，开发者不会通过本应用接收你的记录。
首次进入拍摄页会展示采集说明。在你明确同意本说明并授予相机和麦克风权限之前，不启动相机预览、麦克风采样或位置更新；已有系统权限也不会替代本次明确同意。不同意或返回仍可查看、导出、分享、删除已有本地记录。
同意且相关权限已授予后，进入拍摄页即开始相机预览和实时声音采样；如果授予可选位置权限，也会请求位置更新。离开拍摄页、应用进入后台或锁屏时停止采集。可在“应用信息”中撤回采集隐私同意，停止采集；再次拍摄需要重新同意。撤回不会删除已有记录，也不会自动撤销 Android 系统权限；系统权限可在系统设置中管理。

2. 相机、麦克风与测量数据
相机用于预览、拍摄带测量水印的照片和视频。麦克风采用 48 kHz 单声道采样，计算 A 频率计权、Fast 125 ms 的声级及平均值、最大值等测量数据；录像同时保存声音。照片使用麦克风计算测量水印，不保存独立音频文件。
预览期间在内存中处理画面、声音与近期测量值，不创建已保存的取证记录。点击拍照或录像后，才保存对应记录和媒体；录像开始后持续记录，停止后完成保存。记录可能包含拍摄时间、记录编号、声音测量值及曲线、设备或音频输入信息、测量参考信息和文件校验信息。
本应用显示手机估算的 dB(A)，不替代专业声级计，不保证达到专业计量或司法证明标准。拍摄和分享前，请确认有权处理现场画面、声音与他人的相关信息。

3. 可选位置
位置权限用于在记录与水印中加入可用的经纬度、定位精度与时间。可拒绝位置权限，仍可测量和拍摄；届时显示位置不可用。Android 可能仅提供大致位置或无法定位。定位由 Android 系统的位置服务提供，其权限与可能的网络行为由系统和所选服务管理；本应用自身不联网。

4. 保存、导出与分享
照片、录像、测量 CSV、时间位置与相关元数据保存于本应用的本机存储中；不自动上传。为管理记录，应用也保存记录数据库，以及隐私同意版本等本地设置。本应用禁用 Android 自动备份。
仅在你主动操作时，应用才将照片和视频复制到系统相册，或生成包含媒体、测量数据和校验清单的 ZIP 取证包，并通过 Android 分享或查看界面交给你选择的应用。你选择的接收应用、接收方或系统相册会按其自身规则保存、处理或同步这些副本，可能包含完整声音和位置；请在操作前确认接收对象及其设置。导出包也可能保留在应用的本机临时目录。

5. 删除与卸载
在“本地记录”中删除记录会删除该条应用内记录及其媒体；已保存到系统相册、通过分享发送、另行导出或由其他应用保存的副本不会被一并删除，需要在对应应用、相册或接收方处另行管理。Android 卸载通常删除本应用的私有数据和设置，包括本地记录、临时导出文件与同意状态；系统相册和外部接收方的副本仍可能保留。

6. 说明更新与联系
本说明的重要采集用途变化会通过新的说明版本再次征求同意。项目采用 MIT 许可；本项目许可与第三方开源许可可在“应用信息”中分别查看。隐私问题可通过上述 GitHub Issues 反馈，公开反馈前请先删除敏感内容。
